## 一、验证内容

### 1.1 输出存在性
- 每个 shop 随机抽取 50 个 Excel 文件
- 调用对应清洗器，检查是否有输出及输出行数

### 1.2 输出结构
- 必含列：`part_number`, `shop_name`, `price_new`, `recorded_at`
- 关键字段非空：part_number、price_new 无空值

### 1.3 结构化数据合理性
- `price_new` 为正整数且在合理区间（30,000～500,000 日元）
- 输出行数及 part_number 数量合理

### 1.4 颜色减价信息
- 同文件内不同 part_number 应有价格差异，体现颜色差价
- 若全部同价，记为「全色统一定价」（亦为合理情况）

## 五、结论与建议

### 5.1 总体结论
- **11/12 shop 验证通过**
- 输出结构正确，颜色减价信息在多数样本中均有体现（多档价格）
- **shop13（家電市場）** 有 2 个样本 price_new 超出合理区间，建议：
  1. 检查源 Excel 中异常价格
  2. 在清洗器中增加价格合理性校验或过滤

### 5.2 out=0 说明
- shop3、shop12、shop15 中部分样本 out=0，可能原因：
  - 源文件为空或必选列缺失
  - 无匹配机型/容量
- 按现有验证逻辑，out=0 不记为失败，结论为通过

### 5.3 与 5 样本报告对比
| 项目 | 5 样本报告 | 50 样本报告 |
|------|------------|-------------|
| shop13 | 5/5 OK | 48/50 OK（2 个 price 异常） |
| 其他 shop | 12/12 通过 | 11/12 通过 |
| 样本覆盖 | 每 shop 5 个 | 每 shop 50 个，覆盖更广 |

50 样本测试发现了 shop13 的边界情况，建议后续针对家電市場异常样本做专项排查。
