# 在库商品管理页面使用指南

## 📋 概述

在库商品管理页面是一个功能完整的 Web 界面，用于管理入库商品的状态和信息。提供了直观的用户界面和强大的批量操作功能。

## 🌐 访问地址

```
http://your-domain/inbound-goods/
```

本地开发环境：
```
http://127.0.0.1:8000/inbound-goods/
```

## ✨ 主要功能

### 1. 状态概览

页面顶部显示各状态的商品统计卡片：
- **全部** - 所有库存总数
- **法人预订到货** - 法人预订商品数量
- **个人预订到货** - 个人预订商品数量
- **购买预订到货** - 购买预订商品数量
- **在库** - 当前在库商品数量
- **出货准备** - 待出货商品数量
- **已出货** - 已出货商品数量
- **取消退回** - 退回商品数量
- **状态异常** - 异常商品数量

点击任意卡片可快速筛选该状态的商品。

### 2. 搜索和过滤

**搜索功能**：
- 支持按商品编码搜索
- 支持按特别描述搜索
- 支持按异常备注搜索

**过滤功能**：
- 按状态过滤
- 可组合搜索和状态过滤

### 3. 添加库存

点击右上角 **"添加库存"** 按钮，弹出添加表单：

#### 必填字段：
- **商品类型**：目前支持 iPhone（将来可扩展）
- **选择商品**：从 iPhone 列表中选择，会动态加载所有可用商品
- **唯一商品编码**：格式要求大写字母、数字、连字符和下划线，如 `IPN-MTUW3J-001`
- **在库状态**：选择商品的当前状态

#### 条件字段：
- **预订到货时间**：当状态为"预订到货"类时必填
- **状态异常备注**：当状态为"状态异常"时必填

#### 可选字段：
- **特别描述**：商品的额外说明或备注

**操作步骤：**
1. 选择商品类型（默认 iPhone）
2. 系统自动加载该类型的所有商品
3. 从下拉列表选择具体商品
4. 输入唯一商品编码
5. 选择初始状态
6. 根据状态填写条件字段
7. 点击"创建"按钮

**示例：**
```
商品类型: iPhone
选择商品: MTUW3J/A - iPhone 15 Pro Max 256GB 自然钛金色
唯一商品编码: IPN-MTUW3J-001
在库状态: 在库
特别描述: 全新未拆封，配件齐全
```

### 4. 批量更新状态

批量更新允许一次性修改多个商品的状态：

**操作步骤：**

1. **选择商品**
   - 勾选要更新的商品复选框
   - 或点击表头的全选框选择当前页所有商品
   - 顶部会显示已选择的商品数量

2. **点击批量更新**
   - 点击"批量更新状态"按钮
   - 打开批量更新弹窗

3. **设置新状态**
   - 查看已选择的商品列表
   - 选择新的状态
   - 根据需要填写条件字段（预订到货时间或异常备注）
   - 填写变更原因（可选）

4. **确认更新**
   - 点击"确认更新"按钮
   - 系统会显示更新结果

**注意事项：**
- 只有状态发生变化的商品才会被更新
- 每次更新都会自动创建状态变更历史记录
- 更新失败的商品会在结果中单独列出

### 5. 查看详情

点击商品行的 **眼睛图标** 查看详细信息：

**详情内容：**
- 基本信息：商品编码、关联商品
- 状态信息：当前状态、预订到货时间
- 描述信息：特别描述、状态异常备注
- 时间信息：创建时间、更新时间
- **状态变更历史**：显示最近 10 条历史记录
  - 变更时间
  - 旧状态 → 新状态
  - 变更原因
  - 操作人

### 6. 分页功能

- 每页显示 20 条记录
- 提供首页、上一页、下一页、末页按钮
- 显示当前页码和总页数
- 过滤和搜索条件在翻页时保持

## 🔧 API 端点

页面使用以下 API 端点：

### 1. 获取商品列表
```
GET /inbound-goods/api/products/?type=iphone
```

**响应示例：**
```json
{
    "success": true,
    "products": [
        {
            "id": 1,
            "part_number": "MTUW3J/A",
            "display_name": "iPhone 15 Pro Max 256GB 自然钛金色",
            "model_name": "iPhone 15 Pro Max",
            "capacity": "256GB",
            "color": "自然钛金色"
        }
    ],
    "content_type_id": 15
}
```

### 2. 创建库存记录
```
POST /inbound-goods/api/inventory/create/
Content-Type: application/json

{
    "unique_code": "IPN-MTUW3J-001",
    "product_content_type": 15,
    "product_object_id": 1,
    "status": "IN_STOCK",
    "special_description": "全新未拆封",
    "reserved_arrival_time": null,
    "abnormal_remark": ""
}
```

### 3. 批量更新状态
```
POST /inbound-goods/api/inventory/bulk-update/
Content-Type: application/json

{
    "inventory_ids": [1, 2, 3],
    "new_status": "SHIPPED",
    "change_reason": "批量发货",
    "changed_by": "admin"
}
```

### 4. 获取库存详情
```
GET /inbound-goods/api/inventory/123/
```

## 🚀 使用场景示例

### 场景 1：新商品入库

1. 点击"添加库存"
2. 选择商品类型：iPhone
3. 从列表选择：iPhone 15 Pro Max 256GB
4. 输入编码：`IPN-15PM-256-NT-001`
5. 状态选择：在库
6. 添加描述：全新未拆封，配件齐全
7. 点击创建

### 场景 2：批量预订到货

1. 筛选状态：法人预订到货
2. 全选当前页商品
3. 点击"批量更新状态"
4. 新状态选择：在库
5. 变更原因：预订商品已到货入库
6. 确认更新

### 场景 3：异常商品处理

1. 搜索商品编码
2. 查看详情确认问题
3. 选中该商品
4. 批量更新状态
5. 新状态：状态异常
6. 填写异常备注：外包装破损，需要检查
7. 确认更新

### 场景 4：出货操作

1. 筛选状态：在库
2. 选择要出货的商品
3. 批量更新状态
4. 新状态：出货准备
5. 变更原因：订单 #12345 准备发货
6. 确认更新

## ⚠️ 注意事项

### 数据验证

1. **唯一商品编码**
   - 必须唯一，不能重复
   - 只能包含：大写字母、数字、连字符（-）、下划线（_）
   - 推荐格式：`类型-型号-序号`

2. **预订到货时间**
   - 预订类状态必须填写
   - 使用浏览器的日期时间选择器

3. **状态异常备注**
   - 异常状态必须填写
   - 详细描述异常情况

### 权限要求

- 需要登录才能访问页面
- 创建和更新操作需要适当权限
- 生产环境应启用 CSRF 保护

### 性能优化

- 使用分页减少单次加载数据量
- 商品列表使用 select_related 优化查询
- 批量操作一次处理多条记录

### 浏览器兼容性

- 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- 使用 Bootstrap 5 确保兼容性
- 需要启用 JavaScript

## 🛠️ 故障排查

### 问题 1：商品列表加载失败

**可能原因：**
- API 端点不可用
- 数据库连接问题
- iPhone 表中没有数据

**解决方法：**
1. 检查浏览器控制台错误信息
2. 确认 URL 配置正确
3. 检查数据库中是否有 iPhone 记录

### 问题 2：创建库存失败

**可能原因：**
- 商品编码已存在
- 必填字段未填写
- 条件字段验证失败

**解决方法：**
1. 检查错误提示信息
2. 确认编码唯一性
3. 根据状态填写必需的条件字段

### 问题 3：批量更新部分失败

**可能原因：**
- 某些记录数据验证失败
- 数据库约束冲突

**解决方法：**
1. 查看返回的错误列表
2. 单独处理失败的记录
3. 检查数据完整性
